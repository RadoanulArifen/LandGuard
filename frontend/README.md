# LandGuard frontend

React + Vite + Tailwind CSS + React Router + Recharts + React Flow + Lucide.

```bash
npm install
npm run dev       # http://localhost:5173  (proxies /api to http://127.0.0.1:8000)
npm run build     # production build in dist/
npm test          # smoke test of every page (backend must be running)
```

Pages live in `src/pages`, layouts in `src/layouts`, shared pieces in `src/components`, API calls in `src/services/api.js`.
